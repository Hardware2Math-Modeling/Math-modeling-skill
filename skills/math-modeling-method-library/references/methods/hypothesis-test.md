# 单样本假设检验 (`hypothesis-test`)

- **族/适用性：** 统计分析与数据处理；检验总体均值相对给定基准的双侧偏离。
- **假设：** 独立观测；模板计算 t 统计量但用正态尾部近似，小样本需谨慎。
- **输入/单位：** `values` 与 `null_mean` 使用同一观测单位；统计量和 p 值无量纲。
- **公式/参数：** `t=(mean-mu0)/(s/sqrt(n))`, `p≈erfc(|t|/sqrt(2))`。
- **规模：** `O(n)` 且至少 2 个非恒定观测；精确 t 尾部需要声明的统计依赖。
- **依赖：** Python 标准库。
- **失败信号：** 方差为零、抽样设计遗漏、多重检验未校正、显著但效应微小。
- **验证：** 同报均值差/标准误，检查异常与设计，预先规定多重校正。
- **图表：** `evidence` 均值差与区间；`diagnostic` 样本分布。
- **论文写法：** 报告原假设、双侧方向、统计量、近似 p 值和效应量；未拒绝不是证明。
- **来源边界：** SciPy（BSD-3-Clause）只读参考；统计量实现原创。
