# AHP 加权评分 (`ahp-weighted-score`)

- **族/适用性：** 综合评价与多指标决策；把专家成对判断转成可解释权重。
- **假设：** 判断矩阵正互反，方案分数已同向无量纲化，一致性可接受。
- **输入/单位：** `pairwise` 为无量纲比值；`scores` 为无量纲归一化指标。
- **公式/参数：** 行几何均值得权重，`S_i=sum w_j z_ij`；由 `lambda_max` 计算 `CR`。
- **规模：** `O(m^2+nm)`, `m<=10` 的维护 RI 表；过多指标使判断难审计。
- **依赖：** Python 标准库。
- **失败信号：** 非互反、`CR>0.10`、判断轻微扰动使排名翻转。
- **验证：** 互反性、CR、判断扰动和等权比较。
- **图表：** `evidence` 权重与评分；`diagnostic` 一致性偏差热图。
- **论文写法：** 报告专家来源、尺度、CR 和敏感性，主观权重不写成客观事实。
- **来源边界：** pyAHP（MIT）只读参考；权重与一致性实现原创。
