# 最大流最小割 (`max-flow-min-cut`)

- **族/适用性：** 图论与网络；单源单汇容量网络的最大输送量与瓶颈割。
- **假设：** 有向非负容量，中间节点流守恒，反向残量初值为零。
- **输入/单位：** `nodes` 为标识；`edges=[u,v,capacity]` 为流量单位；`source`,`sink` 为标识。
- **公式/参数：** Edmonds-Karp 反复 BFS 增广；终止时最大流等于最小割容量。
- **规模：** `O(VE^2)`；密集大图需显式选择更高效实现。
- **依赖：** Python 标准库。
- **失败信号：** 负容量、源汇相同、守恒/容量/割等式复核失败。
- **验证：** `0<=flow<=capacity`、节点守恒、重算割容量。
- **图表：** `evidence` 流量/容量与割；`diagnostic` 残量网络。
- **论文写法：** 报告容量单位、守恒、最大流和割集；损耗/共享容量需另行建模。
- **来源边界：** NetworkX（BSD-3-Clause）只读参考；残量算法原创。
