# 线性规划 (`linear-programming`)

- **族/适用性：** 优化与决策；连续可分决策，线性目标与线性容量约束。
- **假设：** 系数确定、单位一致、非负可行域有界；若项目不可分应改查 `mixed-integer-programming`。
- **输入/单位：** `c[j]` 为目标单位/决策单位；`A[i][j]` 为约束单位/决策单位；`b[i]` 为约束单位。
- **公式/参数：** `max c^T x`, `A x <= b`, `x>=0`；模板枚举至多 6 变量的活跃约束组合。
- **规模：** `O(C(m+n,n)n^3)`；大规模实例需预检后使用声明的 LP 求解器。
- **依赖：** Python 标准库；目录中的 `dependencies` 为空，不得静默引入求解包。
- **失败信号：** 无可行顶点、未约束正收益方向、矩阵维度或量纲不一致。
- **验证：** 重算全部约束与目标，比较零方案/人工基线，做容量扰动。
- **图表：** `evidence` 可行域与最优顶点（支撑主张）；`diagnostic` 容量敏感性（探索）。
- **论文写法：** 写明连续可分、有界性、单位和活跃约束；只在模板覆盖的小规模域内陈述最优性。
- **来源边界：** SciPy（BSD-3-Clause）仅作只读概念参考；模板为本仓库 MIT 条款下的原创实现，未复制外部代码。
