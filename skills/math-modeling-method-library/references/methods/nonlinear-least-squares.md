# 非线性最小二乘 (`nonlinear-least-squares`)

- **族/适用性：** 机理模型与数值分析；两参数指数响应 `y=a exp(bx)` 的曲线拟合。
- **假设：** 响应尺度误差独立同方差，初值位于可识别局部盆地。
- **输入/单位：** `x` 为自变量单位，`y` 为响应单位，`initial=[a,b]` 中 `a` 为响应单位、`b` 为 1/x，`iterations` 为次数。
- **公式/参数：** 最小化响应尺度 SSE；解 `(J^T J)delta=J^T r` 的 Gauss-Newton 更新。
- **规模：** `O(iter*n)`，只覆盖两参数指数；多峰/边界问题需别的方法。
- **依赖：** Python 标准库。
- **失败信号：** Jacobian 奇异、SSE/参数发散、多初值分叉。
- **验证：** SSE、残差结构、多初值、留出或重采样不确定性。
- **图表：** `evidence` 观测/拟合/留出；`diagnostic` 残差-x。
- **论文写法：** 报告函数、参数单位、初值、停止条件；拟合好不证明机理真。
- **来源边界：** SciPy（BSD-3-Clause）只读参考；Gauss-Newton 实现原创。
