# K-means 聚类 (`kmeans-clustering`)

- **族/适用性：** 机器学习、分类、聚类与降维；缩放后欧氏空间中的探索性球状分组。
- **假设：** `k` 给定，特征尺度已处理，簇可用均值表达。
- **输入/单位：** `points` 每列为已说明缩放的单位，`k` 为簇数，`max_iter` 为次数；seed 选首个中心。
- **公式/参数：** 最近质心分配与均值更新，最小化簇内平方和；初始化为 seed 控制的最远点序列。
- **规模：** `O(iter*n*k*p)`；目标非凸，初始化敏感。
- **依赖：** Python 标准库。
- **失败信号：** 空簇、多 seed 不稳、非球状结构被错误切分。
- **验证：** 多 seed/k、簇内平方和、业务变量的非因果解释核查。
- **图表：** `validation` 多 seed 共识（支撑稳定性）；`diagnostic` 低维簇图。
- **论文写法：** 报告缩放、k、seed、迭代和稳定性；簇编号无序且不是真实标签。
- **来源边界：** scikit-learn（BSD-3-Clause）只读参考；实现原创。
