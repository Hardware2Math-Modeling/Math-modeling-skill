# 随机森林分类 (`random-forest-classification`)

- **族/适用性：** 机器学习、分类、聚类与降维；有标签、可能非线性的分类基线。
- **假设：** 特征口径一致，标签离散；最小模板是 Bootstrap 随机特征的深度 1 树森林。
- **输入/单位：** `X` 各列记录单位，`y` 为类别，`n_trees` 为棵数；seed 固定抽样。
- **公式/参数：** 每棵树桩以 Gini 最小化选阈值，森林多数投票。
- **规模：** 约 `O(Tnp log n)`，建议 `n<=5000,p<=100`；不等于任意深度生产森林。
- **依赖：** Python 标准库。
- **失败信号：** 标签失衡、时间/组外性能骤降、泄漏造成虚高。
- **验证：** 结构化留出、混淆矩阵、多数类/单树基线、固定 seed。
- **图表：** `evidence` 留出混淆矩阵；`diagnostic` 树桩特征频次。
- **论文写法：** 明示深度 1、树数、seed、切分和基线；频次不作因果重要性。
- **来源边界：** scikit-learn（BSD-3-Clause）只读参考；森林代码原创。
