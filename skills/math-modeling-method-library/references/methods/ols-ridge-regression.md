# OLS 与岭回归 (`ols-ridge-regression`)

- **族/适用性：** 预测、回归与时间序列；连续响应的线性可解释基线与共线性收缩。
- **假设：** 行独立、线性条件均值、特征口径固定；`alpha>=0`。
- **输入/单位：** `X` 每列保留自己的单位并显式包含所需截距列；`y` 为响应单位；`alpha` 的量纲取决于特征缩放。
- **公式/参数：** `(X^T X+alpha I) beta=X^T y`；`alpha=0` 为 OLS。
- **规模：** `O(np^2+p^3)`, `p<=50`；病态高维设计应使用经预检的稳定线性代数。
- **依赖：** Python 标准库。
- **失败信号：** 正规方程奇异、残差结构明显、系数对扰动敏感。
- **验证：** 留出 MSE、残差-拟合图、与均值/未正则化基线比较。
- **图表：** `evidence` 留出预测-观测；`diagnostic` 残差-拟合。
- **论文写法：** 报告特征单位、截距、alpha 来源和切分；关联系数不写成因果。
- **来源边界：** statsmodels（BSD-3-Clause）仅作只读概念参考；正规方程实现原创。
