# 熵权 TOPSIS (`entropy-topsis`)

- **族/适用性：** 综合评价与多指标决策；只对已可行方案做接近度排序。
- **假设：** 指标方向已声明，方案已通过硬约束，列归一化和距离具有业务意义。
- **输入/单位：** `matrix` 各列保留原单位，算法内部转为无量纲；`directions` 为 `benefit`/`cost`。
- **公式/参数：** 熵差异权 `w_j=(1-e_j)/sum(1-e)`；`C_i=d_i^-/(d_i^++d_i^-)`。
- **规模：** `O(nm)`；常数列无信息，TOPSIS 不能替代预算/互斥约束求解。
- **依赖：** Python 标准库。
- **失败信号：** 常数列、异常值主导、归一化或方向改变导致排名翻转。
- **验证：** 方向/单位复核、删列敏感性、等权基线。
- **图表：** `evidence` 贴近度与稳健排名；`diagnostic` 权重/离散度。
- **论文写法：** 限定在评价层，报告方向、归一化、权重和敏感性。
- **来源边界：** scikit-criteria（BSD-3-Clause）只读参考；实现原创。
