# DEA 效率评价 (`dea-efficiency`)

- **族/适用性：** 综合评价与多指标决策；可比决策单元的样本内相对效率。
- **假设：** 最小模板只覆盖单投入/单产出 CCR，投入正、产出非负。
- **输入/单位：** `inputs[i]` 用投入单位，`outputs[i]` 用产出单位；效率无量纲。
- **公式/参数：** `eff_i=(y_i/x_i)/max_k(y_k/x_k)`。
- **规模：** `O(n)`；多投入/多产出必须显式使用 LP，不得由此特例替代。
- **依赖：** Python 标准库。
- **失败信号：** 非正投入、单元技术不可比、前沿异常点主导。
- **验证：** 单位口径、效率 `[0,1]`、删除前沿单元敏感性。
- **图表：** `evidence` 投入-产出前沿；`diagnostic` leave-frontier-out 变化。
- **论文写法：** 明示 CCR 单投入单产出特例，效率仅为样本内相对量。
- **来源边界：** pyDEA 仓库存在，但 GitHub 元数据和仓库根目录均未检测到许可证（2026-08-27 核验）；仅参考方法分类，不使用其源码。本 MIT 模板为原创实现。
