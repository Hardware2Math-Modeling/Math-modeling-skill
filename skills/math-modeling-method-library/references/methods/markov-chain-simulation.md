# 马尔可夫链模拟 (`markov-chain-simulation`)

- **族/适用性：** 随机模拟与不确定性；有限状态、一阶、齐次转移路径。
- **假设：** 下一状态只依赖当前状态，每行概率非负且和为 1，seed 固定。
- **输入/单位：** `transition` 为概率；`initial` 为从 0 开始的状态索引；`steps` 为转移步数。
- **公式/参数：** `P(S_{t+1}=j|S_t=i)=P_ij`，逆累计概率抽样。
- **规模：** `O(steps*k)`, `steps<=1e6`；非齐次/高阶记忆需扩展状态。
- **依赖：** Python 标准库。
- **失败信号：** 行不归一、经验占比与矩阵幂不符、高阶依赖明显。
- **验证：** 概率矩阵、多路径频率与理论概率、不同 seed。
- **图表：** `evidence` 经验/理论状态占比；`conceptual` 转移图。
- **论文写法：** 报告状态、估计窗口、步数和 seed；马尔可夫性/平稳性是待检假设。
- **来源边界：** NumPy（BSD-3-Clause）只读参考；路径抽样实现原创。
