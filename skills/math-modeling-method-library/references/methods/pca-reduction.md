# 主成分分析 (`pca-reduction`)

- **族/适用性：** 机器学习、分类、聚类与降维；相关连续特征的第一线性方差方向。
- **假设：** 行可比、缺失已处理、中心化与是否标准化已明确；模板只提取第一主成分。
- **输入/单位：** `matrix` 各列保留/标准化后的单位；`iterations` 是循环 Jacobi 完整扫描的最大整数预算（默认 20，范围 1–50 次）。每次扫描按固定字典序访问全部 `p(p-1)/2` 个特征对，达到整矩阵证书时提前停止；非整数预算显式拒绝。
- **公式/参数：** 以稳定 Jacobi 旋转同步更新对称协方差 `C` 与正交特征向量矩阵 `V`，直到 `||offdiag(V^T C V)||_F<=1e-12*trace(C)`；再对原协方差重算各列 Rayleigh 商，按最大值及固定列序确定第一特征向量，并要求所选向量满足同一尺度的残差证书 `||Cv-ρv||<=1e-12*trace(C)`。最大绝对载荷的最小索引为符号锚点，重复最大特征值时固定扫描/列序保证可复现。
- **规模：** `O(np²+sweeps·p³)`、内存 `O(np+p^2)`；模板同时物化 `n×p` 输入矩阵与 `n×p` 中心化矩阵，并保留 `p×p` 协方差/Jacobi 状态。每次扫描至多 `p(p-1)/2` 次、每次旋转 `O(p)`，默认最多 20 扫描、扫描预算硬上限 50。纯 Python 模板输入硬上限为 `p<=50`；更大或多成分问题必须改用预检依赖中的稳定 SVD/对称特征求解器。
- **依赖：** Python 标准库。
- **失败信号：** 总方差不大于 `1e-15`、协方差或旋转出现非有限值、整矩阵非对角范数或原协方差残差在预算内未收敛；重复/近重复首特征值虽确定性返回，但方向不唯一或不稳定；单位尺度可能主导载荷。
- **验证：** 同时报出 `off_diagonal_norm`、`convergence_residual`、`convergence_tolerance` 与 `jacobi_sweeps`，检查解释方差比、重复/近重复谱和重采样载荷稳定性，并比较标准化前后结果。
- **图表：** `evidence` 解释方差/得分；`diagnostic` 载荷。
- **论文写法：** 报告中心化、标准化、载荷和解释方差；主成分不自动对应因果机制。
- **来源边界：** scikit-learn（BSD-3-Clause）只读参考；对称 Jacobi 实现原创。
