# 主成分分析 (`pca-reduction`)

- **族/适用性：** 机器学习、分类、聚类与降维；相关连续特征的第一线性方差方向。
- **假设：** 行可比、缺失已处理、中心化与是否标准化已明确；模板只提取第一主成分。
- **输入/单位：** `matrix` 各列保留/标准化后的单位；`iterations` 是每个非零协方差行起点的最大幂迭代预算（默认 100，范围 1–10000 次），任一起点预算内未通过残差检查即显式失败。
- **公式/参数：** 从中心化协方差的全部非零行做多起点幂迭代；仅接受满足 `||Cv-ρv||<=1e-12*trace(C)` 的候选，全部起点认证后取 Rayleigh 商最大的 `v`，得分 `X_c v`。
- **规模：** `O(np²+iter*p³)`，建议 `p<=50`、硬上限 `p<=200`；多成分大规模场景需稳定 SVD。
- **依赖：** Python 标准库。
- **失败信号：** 总方差不大于 `1e-15`、任一非零行起点在预算内未收敛、近重特征值、单位尺度主导。
- **验证：** 解释方差比与收敛残差/容差、重采样载荷稳定、标准化前后比较。
- **图表：** `evidence` 解释方差/得分；`diagnostic` 载荷。
- **论文写法：** 报告中心化、标准化、载荷和解释方差；主成分不自动对应因果机制。
- **来源边界：** scikit-learn（BSD-3-Clause）只读参考；幂迭代实现原创。
