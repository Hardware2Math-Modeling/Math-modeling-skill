# 分段线性插值 (`linear-interpolation`)

- **族/适用性：** 几何、空间与信号；有序节点观测范围内的局部连续估值。
- **假设：** x 严格递增，相邻节点间近似线性，禁止外推。
- **输入/单位：** `x`,`queries` 使用自变量单位；`y` 使用响应单位。
- **公式/参数：** `y(q)=y_i+(y_{i+1}-y_i)(q-x_i)/(x_{i+1}-x_i)`。
- **规模：** `O(q log n)` 且至少 2 节点；重复 x 或域外查询显式失败。
- **依赖：** Python 标准库。
- **失败信号：** 查询越界、节点重复/无序、曲率相对节点间距过大。
- **验证：** 原节点精确复现、留一节点误差、最大节点间距。
- **图表：** `evidence` 节点/线/查询点；`diagnostic` 留一误差。
- **论文写法：** 报告单位、查询域和禁止外推；仅称局部线性近似。
- **来源边界：** SciPy（BSD-3-Clause）只读参考；插值实现原创。
