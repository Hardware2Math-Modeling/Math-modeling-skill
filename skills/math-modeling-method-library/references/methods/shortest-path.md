# 最短路径 (`shortest-path`)

- **族/适用性：** 图论与网络；非负、可加边成本下的源到目标最低成本路径。
- **假设：** 有向图，所有边权非负且使用一个已声明成本单位。
- **输入/单位：** `nodes` 为标识；`edges=[u,v,w]` 的 `w` 为距离/时间/费用之一；`source`,`target` 为标识。
- **公式/参数：** Dijkstra 松弛 `d(v)=min(d(v),d(u)+w_uv)`，并以节点字典序固定并列结果。
- **规模：** `O((V+E)log V)`；负权边显式拒绝，不替换 Bellman-Ford。
- **依赖：** Python 标准库。
- **失败信号：** 负边、目标不可达、边权混合不同量纲。
- **验证：** 逐边累计路径成本、连续性检查、小图人工枚举。
- **图表：** `evidence` 高亮路径和总成本；`conceptual` 拓扑示意不支撑数值最优。
- **论文写法：** 报告方向、边权单位、不可达处理和总成本。
- **来源边界：** NetworkX（BSD-3-Clause）只读参考；Dijkstra 实现原创。
