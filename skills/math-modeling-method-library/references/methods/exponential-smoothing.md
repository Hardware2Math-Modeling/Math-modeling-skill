# 指数平滑 (`exponential-smoothing`)

- **族/适用性：** 预测、回归与时间序列；无明显趋势/季节性的短期水平预测基线。
- **假设：** 等间隔采样，`0<alpha<=1`，水平结构在预测期保持。
- **输入/单位：** `values` 保留观测单位；`alpha` 无量纲；`horizon` 为采样周期数。
- **公式/参数：** `l_t=alpha*y_t+(1-alpha)l_(t-1)`，未来各步为 `l_T`。
- **规模：** `O(T+h)`；发现趋势或季节性时显式选择别的方法，不静默升级。
- **依赖：** Python 标准库。
- **失败信号：** 残差呈趋势/周期、时间不等距、误差对 alpha 极敏感。
- **验证：** 滚动时间切分、朴素预测比较、残差自相关与 alpha 敏感性。
- **图表：** `evidence` 滚动观测-预测；`diagnostic` 残差时序。
- **论文写法：** 报告 alpha、采样周期、预测步长和水平假设。
- **来源边界：** statsmodels（BSD-3-Clause）仅作概念参考；递推实现原创。
