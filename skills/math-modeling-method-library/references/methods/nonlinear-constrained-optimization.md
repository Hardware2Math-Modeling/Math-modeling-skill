# 非线性约束优化 (`nonlinear-constrained-optimization`)

- **族/适用性：** 优化与决策；连续配置中存在边际收益递减。
- **假设：** `sum(a_j x_j-q_j x_j^2)` 为严格凹目标，`q_j>0`，盒约束和总量约束非空。
- **输入/单位：** `linear` 为目标/决策单位，`quadratic` 为目标/决策单位²，`bounds` 与 `sum_limit` 为决策单位；`step_size` 无量纲算法步长。
- **公式/参数：** 投影梯度上升，每步投影到 `[l,u]` 且 `sum x<=B`；`iterations` 为上限。
- **规模：** `O(iterations*n)`；非凸扩展只能作为局部算法，不能沿用本条最优性说明。
- **依赖：** Python 标准库。
- **失败信号：** 目标振荡、投影后违规、多初值显著分叉。
- **验证：** 约束余量、目标轨迹、步长减半与多初值比较。
- **图表：** `validation` 多初值和余量（支撑稳定范围）；`diagnostic` 迭代轨迹。
- **论文写法：** 报告曲率、步长、停止条件与局部/全局界限。
- **来源边界：** SciPy（BSD-3-Clause）仅作概念参考；实现为原创投影算法。
