# 稳健异常值检测 (`robust-outlier-detection`)

- **族/适用性：** 统计分析与数据处理；少量单变量极端观测的稳健筛查。
- **假设：** 多数样本来自同一稳定分布，MAD 非零；标记不等于自动删除。
- **输入/单位：** `values` 为原观测单位；`threshold` 为无量纲修正 z 阈值。
- **公式/参数：** `z_i=0.67448975(x_i-median)/MAD`，`|z_i|>threshold` 标记。
- **规模：** `O(n log n)`；多变量相关异常不是此方法覆盖范围。
- **依赖：** Python 标准库。
- **失败信号：** MAD=0、异常比例过高、阈值微调导致大量翻转。
- **验证：** 回查原记录，比较阈值，保留含/不含标记的两套分析。
- **图表：** `evidence` 原值与经核验标记；`diagnostic` z 分数阈值。
- **论文写法：** 称为“规则标记”，报告阈值/MAD/人工核验，不武断称错误数据。
- **来源边界：** SciPy（BSD-3-Clause）只读参考；MAD 实现原创。
