# 混合整数规划 (`mixed-integer-programming`)

- **族/适用性：** 优化与决策；不可分项目、开关、互斥或逻辑选择，硬约束必须直接满足。
- **假设：** 最小模板的变量全部为二元，系数确定且单位一致，穷举规模可承受。
- **输入/单位：** `c[j]` 为每项收益（目标单位）；`A[i][j]` 与 `b[i]` 共用约束单位。
- **公式/参数：** `max sum c_j x_j`, `A x<=b`, `x_j in {0,1}`；枚举 `2^n` 个候选。
- **规模：** `n<=22`, `O(2^nmn)`；更大实例必须使用经 preflight 确认的求解器并报告 gap。
- **依赖：** Python 标准库；风险或情景扩展不是此 stable id 的隐含组成。
- **失败信号：** 无可行方案、穷举规模超限、连续松弛与整数方案差距异常。
- **验证：** 逐条重算预算/服务/互斥约束，与全零和贪心基线比较，核对枚举数。
- **图表：** `evidence` 入选项目与约束余量；`diagnostic` 候选目标分布。
- **论文写法：** 主模型记录为此 id；CVaR、情景或非线性收益另列可选扩展，无 gap 不声称通用全局最优。
- **来源边界：** PuLP（MIT）仅作只读概念参考；本模板为原创二元穷举，未复制求解器代码。
