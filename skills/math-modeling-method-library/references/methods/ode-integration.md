# 常微分方程数值积分 (`ode-integration`)

- **族/适用性：** 机理模型与数值分析；常参数标量 `dy/dt=rate*y+forcing` 初值轨迹。
- **假设：** 非刚性线性 ODE，参数在积分区间不变，固定步长足够小。
- **输入/单位：** `y0` 状态单位；`rate` 为 1/时间；`forcing` 为状态/时间；`dt` 为时间；`steps` 为步数。
- **公式/参数：** 经典 RK4 四个斜率加权更新。
- **规模：** `O(steps)`；刚性、多状态或事件问题不在模板覆盖内。
- **依赖：** Python 标准库。
- **失败信号：** 步长减半后差异大、非物理状态、量纲不闭合。
- **验证：** 与线性解析解比较、步长减半、初值/量纲检查。
- **图表：** `evidence` 经误差检查的轨迹；`diagnostic` 多步长差值。
- **论文写法：** 给出方程、单位、初值、RK4 和收敛证据；数值拟合不证明机理。
- **来源边界：** SciPy（BSD-3-Clause）只读参考；RK4 实现原创。
