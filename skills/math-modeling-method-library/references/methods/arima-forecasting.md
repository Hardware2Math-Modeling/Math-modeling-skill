# ARIMA 预测 (`arima-forecasting`)

- **族/适用性：** 预测、回归与时间序列；一次差分后近似 AR(1) 的等间隔序列。
- **假设：** 固定 ARIMA(1,1,0)，差分残差近似白噪声，`|phi|<1`。
- **输入/单位：** `values` 为按时间排序的原单位观测；`horizon` 为采样周期数。
- **公式/参数：** `Delta y_t=phi Delta y_(t-1)+e_t`；无截距最小二乘估计 `phi` 后递推水平。
- **规模：** `O(T+h)` 且至少 4 点；季节项、阶数选择不是模板隐藏功能。
- **依赖：** Python 标准库。
- **失败信号：** lag 方差为零、`|phi|>=1`、差分残差仍自相关。
- **验证：** 滚动原点回测、与随机游走比较、差分残差 ACF。
- **图表：** `evidence` 回测预测；`diagnostic` 差分残差 ACF。
- **论文写法：** 明确写 ARIMA(1,1,0)、phi、稳定性、窗口和预测边界。
- **来源边界：** statsmodels（BSD-3-Clause）仅作概念参考；估计与递推代码原创。
