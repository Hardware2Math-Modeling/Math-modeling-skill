# 演化复制动态 (`evolutionary-replicator`)

- **族/适用性：** 博弈与多主体决策；固定对称收益矩阵下的大群体策略份额演化。
- **假设：** 连续份额、充分混合、固定收益、Euler 步长足够小。
- **输入/单位：** `payoff` 为效用，`initial` 为比例，`dt` 为时间，`steps` 为步数。
- **公式/参数：** `dx_i/dt=x_i[(Ax)_i-x^T A x]`；每步数值归一回单纯形。
- **规模：** `O(steps*k²)`；大 dt 会产生离散误差。
- **依赖：** Python 标准库。
- **失败信号：** 离开单纯形、dt 减半差异大、现实收益非平稳。
- **验证：** 非负归一、dt 减半、固定点相对收益。
- **图表：** `evidence` 经步长检查的份额轨迹；`diagnostic` 平均收益/单纯形误差。
- **论文写法：** 报告收益、初值、dt 和固定收益假设；稳定不等于规范最优。
- **来源边界：** Nashpy（MIT）只读参考；Euler 实现原创。
