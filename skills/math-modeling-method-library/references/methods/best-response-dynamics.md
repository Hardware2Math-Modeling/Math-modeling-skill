# 最佳反应动态 (`best-response-dynamics`)

- **族/适用性：** 博弈与多主体决策；两玩家按固定顺序交替采用纯最佳反应。
- **假设：** 收益固定完全已知，更新顺序为行后列，并列取最小索引。
- **输入/单位：** 两个同形收益矩阵为效用；`initial=[i,j]` 为策略索引；`steps` 为轮数。
- **公式/参数：** `i'=argmax_i A_ij`, `j'=argmax_j B_i'j`。
- **规模：** `O(steps*(m+n))`；一般博弈不保证收敛，循环是有效结果。
- **依赖：** Python 标准库。
- **失败信号：** 策略循环、并列规则改变终点、收益扰动导致翻转。
- **验证：** 逐步重算，改变初值/并列规则，收敛点核对纯纳什条件。
- **图表：** `validation` 策略轨迹与循环；`conceptual` 更新顺序。
- **论文写法：** 报告顺序、并列、初值和循环；有限步停留不自动称均衡。
- **来源边界：** Nashpy（MIT）只读参考；动态实现原创。
