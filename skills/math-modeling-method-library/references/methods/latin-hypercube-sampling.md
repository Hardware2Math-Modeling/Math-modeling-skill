# 拉丁超立方采样 (`latin-hypercube-sampling`)

- **族/适用性：** 随机模拟与不确定性；有限矩形参数空间的边际分层覆盖。
- **假设：** 每维有限有序边界，维度独立排列，seed 固定。
- **输入/单位：** `bounds[j]=[low,high]` 保留该参数单位；`samples` 为样本数。
- **公式/参数：** 每维将 `[0,1]` 分为 n 层，各层取一点、打乱，再线性映射。
- **规模：** `O(np)`；不保证高维投影或相关结构的最优空间填充。
- **依赖：** Python 标准库。
- **失败信号：** 无穷/反向边界、高维稀疏、相关参数被当作独立。
- **验证：** 每维每层恰一值、边界检查、与 iid 覆盖比较。
- **图表：** `validation` 二维分层占用；`diagnostic` 样本相关矩阵。
- **论文写法：** 报告边界、单位、n、seed；LHS 设计不自动给概率权重。
- **来源边界：** SciPy（BSD-3-Clause）只读参考；LHS 实现原创。
