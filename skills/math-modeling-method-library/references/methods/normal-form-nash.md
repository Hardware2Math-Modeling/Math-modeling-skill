# 标准型博弈纯策略纳什均衡 (`normal-form-nash`)

- **族/适用性：** 博弈与多主体决策；两玩家有限策略收益矩阵的纯均衡枚举。
- **假设：** 完全信息、同时行动、效用可比较于各玩家自身偏好；仅覆盖纯策略。
- **输入/单位：** `row_payoffs`,`column_payoffs` 为同形收益矩阵，单位为各玩家效用。
- **公式/参数：** `(i,j)` 同时满足列固定时行玩家最佳反应、行固定时列玩家最佳反应。
- **规模：** 直接检查约 `O(mn(m+n))`；无纯均衡返回空，不静默替换混合均衡。
- **依赖：** Python 标准库。
- **失败信号：** 空均衡集、收益量化缺证、微小扰动使均衡消失。
- **验证：** 逐均衡检查单边偏离，扰动收益，明确纯策略边界。
- **图表：** `evidence` 矩阵最佳反应交点；`conceptual` 互动示意。
- **论文写法：** 报告参与者、策略、收益单位和纯策略限定。
- **来源边界：** Nashpy（MIT）只读参考；枚举实现原创。
