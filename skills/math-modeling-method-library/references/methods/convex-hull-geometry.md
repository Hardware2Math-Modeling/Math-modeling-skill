# 二维凸包 (`convex-hull-geometry`)

- **族/适用性：** 几何、空间与信号；二维点集的最小凸包络。
- **假设：** 有限欧氏平面坐标；共线中间点不保留为顶点。
- **输入/单位：** `points=[[x,y],...]`，两坐标使用已声明空间单位和同一投影。
- **公式/参数：** Andrew 单调链，扫描时对叉积 `<=0` 弹栈。
- **规模：** `O(n log n)`；仅二维，不表示非凸真实边界或内部占据。
- **依赖：** Python 标准库。
- **失败信号：** 坐标投影/单位混用、全共线却解释为面积、凸包掩盖空洞。
- **验证：** 所有点在边同侧/边上，顶点次序，小点集人工核对。
- **图表：** `evidence` 点集与凸包；`conceptual` 凸包和非凸边界差异。
- **论文写法：** 报告坐标系、单位和共线处理，不断言凸包内部均被占据。
- **来源边界：** SciPy（BSD-3-Clause）只读参考；单调链实现原创。
