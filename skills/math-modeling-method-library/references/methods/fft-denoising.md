# FFT 频域去噪 (`fft-denoising`)

- **族/适用性：** 几何、空间与信号；等间隔实信号的低频 DFT 截断演示。
- **假设：** 等间隔采样、周期边界近似、信号能量集中在保留低频。
- **输入/单位：** `values` 为信号单位；`keep_frequencies` 为含直流的最低非负频率个数；采样间隔需在论文另报。
- **公式/参数：** 直接 DFT，保留低频及其共轭，再逆 DFT；虽然 id 沿用 FFT 类别，模板计算为可审计 `O(N²)` DFT。
- **规模：** `N<=2048`, `O(N²)`；生产规模需预检 NumPy/SciPy FFT，不得隐藏调用。
- **依赖：** Python 标准库。
- **失败信号：** 关键成分被削弱、端点泄漏、采样不等距。
- **验证：** 合成频率恢复、截断敏感性、重构 MSE 和保留频率。
- **图表：** `evidence` 原始/去噪/保留频谱；`diagnostic` 全频谱与端点跳变。
- **论文写法：** 报告采样间隔、长度、保留频率和周期边界；平滑不等于真实恢复。
- **来源边界：** NumPy（BSD-3-Clause）只读参考；DFT 实现原创。
