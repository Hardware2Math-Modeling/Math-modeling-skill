# 热方程有限差分 (`finite-difference-heat`)

- **族/适用性：** 机理模型与数值分析；一维常扩散系数、固定边界热/扩散过程。
- **假设：** 均匀网格，固定 Dirichlet 边界，显式稳定性条件成立。
- **输入/单位：** `initial` 为温度/浓度，`alpha` 为长度²/时间，`dx` 长度，`dt` 时间，`steps` 步数。
- **公式/参数：** `u_i^{n+1}=u_i^n+r(u_{i-1}^n-2u_i^n+u_{i+1}^n)`, `r=alpha*dt/dx²`。
- **规模：** `O(steps*grid)` 且 `r<=0.5`；仅一维常系数。
- **依赖：** Python 标准库。
- **失败信号：** `r>0.5`、振荡/越界、网格加密不收敛。
- **验证：** 稳定数、边界保持、`dx/dt` 网格收敛。
- **图表：** `evidence` 经收敛的剖面；`diagnostic` 多网格差值。
- **论文写法：** 报告 PDE、边初值、alpha 单位、r 和网格收敛。
- **来源边界：** SciPy（BSD-3-Clause）只读参考；显式格式原创。
