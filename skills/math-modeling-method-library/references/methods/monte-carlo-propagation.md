# 蒙特卡洛不确定性传播 (`monte-carlo-propagation`)

- **族/适用性：** 随机模拟与不确定性；独立正态输入乘积的输出分布。
- **假设：** 输入相互独立且正态，输出等于乘积，seed 固定。
- **输入/单位：** `means`,`stds` 各自保持输入单位；`samples` 为次数；输出单位为各输入单位乘积。
- **公式/参数：** `X_j~N(mu_j,sigma_j²)`, `Y=product X_j`；输出均值、标准差、5%/95% 分位数。
- **规模：** `O(samples*p)`, `samples<=200000`；相关或截断分布需显式改模。
- **依赖：** Python 标准库。
- **失败信号：** 统计量随 seed/n 波动、生成非物理输入、忽略相关性。
- **验证：** 增大样本量、零方差解析值、分布/相关情景。
- **图表：** `evidence` 输出分布和分位数；`diagnostic` 累计均值收敛。
- **论文写法：** 报告分布、单位、独立性、样本量和 seed，区间绑定假设。
- **来源边界：** SciPy（BSD-3-Clause）只读参考；采样传播实现原创。
