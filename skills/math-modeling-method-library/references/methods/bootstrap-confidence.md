# Bootstrap 置信区间 (`bootstrap-confidence`)

- **族/适用性：** 统计分析与数据处理；iid 样本均值的非参数百分位区间。
- **假设：** 行可交换且代表目标总体；重采样单位是一条观测；seed 固定。
- **输入/单位：** `values` 保留观测单位；`resamples` 为次数；`confidence` 为无量纲比例。
- **公式/参数：** 有放回抽 `n` 个观测计算均值，取双尾经验分位数。
- **规模：** `O(Bn)`, `B<=100000`；时间/群组数据需改变重采样单位。
- **依赖：** Python 标准库。
- **失败信号：** 样本不代表、端点随 B/seed 波动、相关结构被忽略。
- **验证：** 增大 B、与解析区间比较、按生成结构复核抽样单位。
- **图表：** `evidence` Bootstrap 分布与区间；`diagnostic` 端点收敛。
- **论文写法：** 报告 B、seed、区间类型和代表性限制，不把置信区间解释为单次参数概率。
- **来源边界：** SciPy（BSD-3-Clause）只读参考；重采样实现原创。
